# Main Page

Welcome to this wiki. It was created with **WikiForge**, and every article is a Markdown file in the `pages` folder.

## Getting started

Open the [[Showcase]] article from the sidebar to see every kind of content an article can hold: mathematics, tables, spreadsheets, graphs, code windows, maps, timelines, audio, searchable CSV data and 3D models.[^1] The home page shows how all the articles are connected on an interactive site map.

[^1]: Use the editor's *Page* menu and choose *Generate showcase page* to add the showcase article to any site.
